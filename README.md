# POWERWIKI

跨宇宙战力论战 · 量级标准与元规则库。

## 站点

静态站点，源码位于 `main` 分支根目录，通过 GitHub Pages 发布。

- `index.html` — 站点主页（元规则 / 换算公式 / 量级分级 / 角色库）
- `.nojekyll` — 禁用 Jekyll 处理，避免下划线前缀文件被忽略

## 量级换算基准

```
E = 2π D² × F*
F* = 1.64 × 10²³ J/m²
1 AU = 1.496 × 10¹¹ m
```

`D` 为恒星系**直径**。全体系统一使用直径表述，不使用半径。

## 数据更新

角色数据来自 `powerwiki.db`（SQLite）。导入新 db 后重新导出站点并覆盖推送本分支，
GitHub Pages 会自动重新部署。
